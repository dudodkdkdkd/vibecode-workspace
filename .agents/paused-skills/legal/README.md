# Rechtsskills auf Abruf

Öffne die jeweilige `skills/<name>/SKILL.md` erst auf ausdrücklichen Auftrag.
Versand, Signaturen und Änderungen in verbundenen Diensten brauchen eine eigene
Beauftragung. `CONNECTORS.md` dokumentiert die Verbindungen des Originalpakets.

- Anthropic liefert `brief`, `compliance-check`, `legal-response`,
  `legal-risk-assessment`, `meeting-briefing`, `review-contract`,
  `signature-request`, `triage-nda` und `vendor-check`. Die Dateien entsprechen
  der [geprüften Fassung `0e0fcac`](https://github.com/anthropics/knowledge-work-plugins/tree/0e0fcacddcc892eb92a1b7873ff9d68159c47571/legal).
  Für diese Dateien gilt die beiliegende [Apache-2.0-Lizenz](LICENSE).
